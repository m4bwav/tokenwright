# Books for tokenwright

Candidates, what each adds, which skill it feeds. Reading notes live outside this repository in the book-learnings notes (tokenwright-lean-goal.md); nothing here quotes a book.

| Book | Adds | Feeds | Status |
|---|---|---|---|
| Ohno, *Toyota Production System* (1988) | The seven wastes as a vocabulary for token waste; stop at the first defect; standard work written where the work happens | hub `references/waste-vocabulary.md`, tw.py sink names, tokenwright-script | Read 2026-10-30 |
| Womack and Jones, *Lean Thinking* | Value stream (value, needed for now, removable now); pull not push; single-piece flow (one script call instead of many turns) | hub family 2, tokenwright-script | Read 2026-10-30 |
| Goldratt, *The Goal* | Find the bottleneck before optimising; five focusing steps as the hub's method | hub "Method", tw.py ranking | Read 2026-10-30 |
| Huyen, *AI Engineering* | Context budgets, cost per query, eval design | levers, evals | Read 2026-10-22 for another plugin; notes reused |
| Hunt and Thomas, *The Pragmatic Programmer* | Automate the repeated; don't repeat yourself | tokenwright-script | Read 2026-10-30 |
| Christian and Griffiths, *Algorithms to Live By* | Caching and eviction, optimal stopping, explore and exploit | family 2 (stop early, answer from cache) | Read 2026-10-30 |
| Meadows, *Thinking in Systems* | Leverage points: where a small change saves most | tokenwright-skills ranking | Next (on disk) |
| Berryman and Ziegler, *Prompt Engineering for LLMs* | Context assembly and budgets | levers | Not on disk |

Skip: Voss, *Mastering Claude Code* (invents commands; judged junk in the earlier book pass).
