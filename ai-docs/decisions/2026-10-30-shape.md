# Decision: plugin shape (2026-10-30)

- Name: tokenwright, as the kickoff suggested. No clearly better name found; it fits the *-wright family. The maintainer may rename.
- Three skills (hub, script, skills) instead of one: their triggers differ (a session is expensive; a job repeats; a skill is being written), and each body stays small. The cost is about 420 description characters every session; budget.py keeps all descriptions under 1,500.
- tw.py ranks sinks by carried cost (tokens times later turns), not size: an early sink is re-read as cache on every later turn. Measured on real sessions it changes the order.
- Usage counted once per requestId: transcripts repeat a response's usage on each content line.
- Hooks ship in the plugin but are inert until TOKENWRIGHT_HOOKS is set: The brief said off by default. Each Read still spawns python briefly; if that matters, remove hooks.json and document manual setup instead.
- skill-tidy stays separate for now (a stop point for the maintainer); tokenwright-skills links to it.
